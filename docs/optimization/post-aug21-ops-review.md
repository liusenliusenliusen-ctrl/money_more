## 2. 主判断

闸门在干活，但「研究很多、建议为零、模拟盘僵尸持仓」已经连续五轮。  
近两周全 watch，在 high + PMI + 微观偏紧下是**合理输出**，不要为了模拟盘有交易而放松门禁。

## 3. 优化项（按杠杆）

### P0-1 部署已写好的三包到服务器

**问题**：线上仍是旧行为。

- 板块资金来源标记 `ths_summary`（偏「今日」），不是近 5 日主序列。  
- digest 里 `contradiction_branches` 为空（有展示文案，但未写入可跨轮的 `branch_id`）。  
- 社融双源 `conflict` 只进台账，不发丝。  
- 连接分报 1.0，研究完整度 0.0（Tushare 盈利修正/预告/双源估值不可用）。  
- 本地三包已有：5 日扩池、社融滞后期、冲突 haircut、跨轮分支、现金地板、主题帽、quote 缺失不假装盯市。

**改法**：把本地 `main`（含三包 commit）同步到 `/opt/money_more`；**不**用本地残缺 `reports/` 覆盖线上报告。同步后先不强制冒烟，等下一轮 scheduled。

**验收**：下轮台账板块资金窗口为 5d 或明确「5 日不可用 + 空扩池」；digest 带 `branch_id`；社融滞后/冲突在 DQ 或 overrides 可见。

**状态**：本轮先做同步（见文末「本轮已做」）。

### P0-2 模拟盘与建议脱节（产品漏洞）

**问题**：A3 按空仓只出 buy/watch，**不会给已有模拟仓写 hold/sell**。  
8/5 买入的 `000725`、`300059` 一直挂着：无 thesis 复检、无卖出。  
多日现价卡在成本（8/11、8/18、8/21 均为 6.07 / 20.36）——缺报价时用成本冒充盯市。

**改法方向**：

- A3 增加「纸面持仓」通道，或把 sim 持仓当 `paper_holdings` 强制进深度池。  
- 每轮必须对纸面仓给出 hold / add / sell。  
- 缺报价 → `mtm_ok=false`，禁止用成本冒充市值（本地 sim 已有部分修复，须确认线上生效并覆盖遗留仓）。

**验收**：有模拟仓时 A3 出现对应 hold/sell；缺价日权益不假装持平成本。

**状态**：待下一轮动手。

### P2-1 数据诚实：连接分不能再报 1.0

每轮稳定现象：

- 东财现货失败 → 新浪（通常无 PE/PB）  
- Tushare 研究字段全空  
- 社融双源冲突  
- 数库 ChinaScope SSL 常年挂掉  

台账已写「研究完整度 0」，主分仍 1.0，LLM 容易把估值故事讲满。

**改法**：三包的缺估值打 40、社融滞后扣分应对齐线上；研究层 0 分时连接分封顶；数库情绪可标 skip，不进失败噪声。Tushare 权限是配置/积分问题，比再写一层叙事有用。

**状态**：代码部分已在三包；线上对齐 + 连接分封顶仍待收口。

### P2-2 矛盾分支要「确认一条动一条」

**问题**：8/11 卡上仍是「PMI 49.2 → 禁进攻」，没有跨轮 `improved/worsened`。PMI 按月更新，周二/五连跑会把一个月旧数当成每日新矛盾。

**状态**：跨轮评估已在本地三包；「月频不每周重激活」待设计。
