# 中长线「去短线灵敏度」优化草案

> 状态：**讨论结论草案，待确认后实施**（本会话约定：先讨论、按命令成文，不直接改代码）  
> 日期：2026-08-01  
> 背景：中长线定位旨在减少不确定性对决策的牵引；当前管道中仍有日度涨跌、短窗资金、快讯舆情等「短线零件」。本草案约定如何收束这些零件，而不改变「公开信息 + 硬门禁 + 侧栏假说」的严谨态度。

---

## 1. 目标与非目标

### 1.1 目标

1. **进池**：少被当日热点/暴涨票占满深度研究预算。  
2. **打分**：因子卡不再用短窗量价/情绪当「更好股票」的加分理由。  
3. **语料**：快讯与人气不主导 A1/digest 温度；保留事件线索能力。  
4. **风控**：微观结构继续服务「机制失灵时少开仓」，语义不滑向短线择时。

### 1.2 非目标（本轮不做）

- 不引入灰色/内幕信息源；国家队/操纵类叙事仍侧栏，须确认才升权。  
- 不改成短线交易系统，也不追求提高短期涨跌命中率。  
- 不扩大自动下单或实盘接口。

### 1.3 验收直觉

若将「当日涨跌、3–5 日主力线性加分、人气/电报情绪」静音后，主结论方向与仓位逻辑应大体仍站得住；若静音后结论塌掉，说明仍过度依赖短线灵敏度。

## 3. 进池：暴涨当日剔除

### 3.1 现状

量化打分含当日 `change_pct` 权重 15%，且 `_chg_to_score` 已对暴涨降权（反追高），**并非追涨选股**。暴涨票仍可能因估值/成交额较高而进入量化池/深度池。

### 3.2 目标行为

- **新票**：当轮若满足「暴涨」阈值 → **不得进入量化池前列，也不得进入深度池**（直接剔除）。  
- **声明持仓**（`holdings`）：仍强制进深度池，**不受暴涨剔除约束**。  
- 打分公式中的当日涨跌项：实施时可 **移出主打分**（避免与硬剔除重复）；成交额改为多日均值见 §6 P1。

### 3.3 建议阈值（实施前可再定一条）

| 项 | 建议初值 | 说明 |
|----|----------|------|
| 暴涨剔除 | 当日涨跌幅 **≥ 7%** | 覆盖明显脉冲；略宽于「仅涨停」 |
| 备选更严 | ≥ 5% 或 ≥ 9% | 5% 更严、9% 更松；默认先 7% |
| ST/*N 等 | 沿用现有硬过滤 | 不在本条重复 |

报告/筛选摘要应写明：`excluded_surge_count` 及示例代码，避免误以为「没扫到」。

### 3.4 涉及模块（实施时）

- `analysis/screen.py`：硬过滤或选深前剔除；更新 `plain_note` / `filter_stats`  
- 测试：`tests/test_stock_screen.py`  
- 文档：`docs/data-sources-guide.md` / README 术语表可补一句「暴涨当日不进新票深度池」

## 4. 舆情：框架下最合理选择（已写入草案）

### 4.1 判断依据

- 舆情（新闻词典分、人气榜、雪球热度）**天然偏滞后**，且易被标题/热钱污染。  
- 中长线主驱动应是：流动性硬指标、盈利预期修正、估值/质量、可核对政策。  
- 未确认网络叙事**不得单独驱动买入**（现有原则，保持）。  
- 因子卡若仍给舆情「高分=更好」，会与上述原则冲突。

### 4.2 选定方案（综合）

> **舆情定位为「拥挤度与温度调节器」，不是 alpha 加分项；语料分流后，只有主线池进综合舆情，噪声池只做事件/拥挤旁路。**

具体约定：

| 层级 | 做法 |
|------|------|
| **因子卡 `sentiment`** | 取消「舆情分高 → 总分升高」的主路径；改为以 **拥挤度惩罚** 为主（高拥挤降分或触发降权标记）。无拥挤数据时中性（~50），不因快讯条数偏多而抬分。 |
| **语料分流** | **主线池**：政策/联播、Tushare 宏观、宏观硬指标相关、经济日历要点等 → 可参与 `sentiment_overview`（温度描述）。**噪声池**：电报/全球碎资讯/人气标题 → 不进综合舆情主分；仅事件扫描、叙事雷达、拥挤旁路。 |
| **人气榜 / 雪球** | 退出 A1「舆情偏暖/偏冷」主叙事；仅服务 **拥挤度**（个股/板块）。 |
| **权重** | 默认 `sentiment` 权重下调（建议 ≤5%）；或保留权重但内部只实现拥挤惩罚（效果等价于「不奖励热闹」）。 |
| **LLM** | Prompt 明确：舆情/人气不得作为 buy/add 主证据；拥挤高 → 更宜降仓位或推迟加仓。侧栏叙事规则不变。 |

### 4.3 不选的方案（及原因）

| 方案 | 为何不选 |
|------|----------|
| 维持现状（舆情可线性加分） | 与中长线、反滞后判断冲突 |
| 完全删除舆情模块 | 丢掉拥挤度这一有用的风险信号，过猛 |
| 靠 LLM「自觉降权」 | 规则分已算好，口头约束不可靠 |

### 4.4 涉及模块（实施时）

- `analysis/factor_scorecard.py`、`analysis/sentiment.py`  
- `data/intelligence.py`（新闻池拆分后再打分）  
- `llm/prompts.py`（DECISION / MARKET / DIGEST）  
- `analysis/context_builder.py`（控制送入上下文的热榜长度与语义）  
- 报告表述：`report/writer.py` 中「舆情」措辞改为「拥挤/温度」优先

## 5. 微观结构：重度单日禁，轻/中度确认后禁

### 5.1 语义（保持）

微观结构回答的是：

> 常规「基本面 → 价格」传导是否暂时不可用？  

动作用途是 **降杠杆 / 禁新开仓**，不是预测次日涨跌。报告文案应统一为「机制压力 / 传导受扰」，避免「情绪看空」表述。

### 5.2 Regime 分档（建议）

在现有 `normal / elevated / crowded_sync / liquidity_stress` 上明确操作映射：

| 分档 | 典型含义 | 新开仓（buy/add） | 总仓 |
|------|----------|-------------------|------|
| **轻度** | 如单独 `crowded_sync`、同向性偏高但未到枯竭 | 不禁；进入「观察」 | 可 ×0.85 |
| **中度** | 多项 flag 初现，或 `liquidity_stress` 仅单薄触发 | 不禁；记 `pending_stress` | 可 ×0.85 |
| **重度** | `liquidity_stress` 且 **多信号共振**（见下） | **本轮立即禁新买** | 建议 ×0.7（可沿用现逻辑） |

**多信号共振（重度）建议条件（实施时可调参）：**  
在 `liquidity_stress`（或等价）基础上，下列至少再满足 **2** 条（或「stress + 1 条极强」）：

- 跌停家数或涨跌停合计超过现有高阈值  
- 上涨或下跌家数占比极端（如 ≥75%）  
- 成交额前 50 占比过高  
- 北向净流出超过大幅阈值  
- 主要指数单日波动过大  

（具体数字对齐 `market_microstructure.py` 现有阈值，避免两套标准。）

### 5.3 轻/中度如何「确认」

| 步骤 | 行为 |
|------|------|
| 本轮轻/中度 | **不禁新买**；总仓可降权；digest/结论卡标注「结构压力观察中」；写入本轮 `microstructure.regime` / `pending_confirm=true` |
| 确认条件 | **上一成功运行** 已是轻/中度或重度压力，**且本轮仍为轻/中度或升级** → 本轮 **禁新买** |
| 解除 | 本轮回到 `normal` / `elevated` → 清除待确认，恢复常规 |

存储：依赖上次 run 的结果（DB 或 `reports/*.json` / digest 中的 microstructure 快照）。若无上轮数据（首跑），轻/中度仅降权不禁；重度仍单日禁。

### 5.4 与现有门禁关系

- 全球流动性收紧、数据质量过低、信息缺口等 **现有硬门禁保留**，与微观结构正交叠加（取更严者）。  
- 空仓 / 深度池白名单规则不变。

### 5.5 涉及模块（实施时）

- `analysis/market_microstructure.py`：输出 `severity` / `severity_level` / `pending_confirm`  
- `analysis/decision_validator.py`：按分档禁买与仓位系数  
- `analysis/pipeline.py`：读上轮 microstructure  
- `report/writer.py`：结论卡简短说明「观察中 / 已确认禁新开仓 / 重度单日禁」  
- 测试：微观结构分档 + 跨轮确认

## 6. 建议实施顺序

### P0（先关掉错误激励）

1. 进池：**暴涨当日剔除**（§3）  
2. 舆情：**拥挤调节器 + 主线/噪声池分流**（§4）  
3. 因子卡附属（与 §4 同批更干净）：  
   - `momentum`：去掉日涨跌、`MA5>MA20` 主加减分；改为 20–60 日趋势类  
   - `fund_flow`：取消 3–5 日净流入线性加分；改为短长窗一致性 / 背离惩罚  

### P1（进池进一步中长线化）

4. 成交额：当日 → 20/60 日均额或分位  
5. 打分公式：移除当日 `change_pct` 权重（已由硬剔除覆盖）  
6. `auto_sector_from_flow`：近 1 日流入仅「观察扩」；多日同向或与叙事雷达重叠才「升权扩」  

### P2（微观结构分档确认）

7. 落地 §5：重度单日禁；轻/中度跨轮确认  
8. 报告语义统一为机制压力  

### P3（有余力）

9. 进池增加中期 prelim（盈利修正/质量等，依赖 Tushare 完备度）  
10. 辩论题单去盘面化（盈利/估值/失效/信息完备为主）

## 8. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 暴涨剔除过严，漏掉「中期逻辑刚兑现」的票 | 阈值可调；持仓不受影响；报告暴露剔除统计，复盘后再调 7%→9% |
| 舆情不再加分，组合更「钝」 | 预期内：中长线要的是少追热，不是更灵敏 |
| 轻/中度确认导致极端前夜仍开仓 | 重度单日禁兜底；可与全球流动性等门禁叠加 |
| 无上轮状态时确认逻辑失效 | 首跑：轻/中度仅降权；重度仍禁 |

回滚：配置开关回到 legacy（不剔除暴涨、舆情可加分、微观结构一律按旧 stress 处理）。

## 9. 与现有严谨原则的关系（不变）

- 未声明持仓 = 空仓  
- 深度池外禁止 buy/add  
- 未确认叙事不得单独驱动买入  
- 政策市 / 国家队 / 操纵类：侧栏假说 + 可观察代理，不假装可知幕后  
- 自优化仍优先补数据源，再改分析；**本草案实施前建议 `OPTIMIZE_PAUSE`，避免自优化与人工方案打架**
