# money_more 报告解读指南

面向「想看懂报告、但不想当交易员」的读者。  
配套报告由 `report/writer.py` 生成（标题为「中长线周期决策报告」）。

---

## 0. 先记住四件事

### 阅读分层（主结论 vs 侧栏）

| 层级 | 写什么 | 怎么用 |
|------|--------|--------|
| **【主结论】** | 阶段、配置、买卖动作 | 可执行、可复核 |
| **【机制层】** | 同向性、跌停潮、成交集中等微观结构 | 可进入仓位纪律，≠「量化有罪」 |
| **【侧栏】** | 争议叙事、政策市假说、叙事雷达 | 须确认/证伪；不能单独当买入理由 |

### 持仓怎么算

| 概念 | 是什么 | 不是什么 |
|------|--------|----------|
| **声明持仓** `holdings` | 你明确写入 `config.yaml` 的真实仓位 | — |
| **未声明 / `[]`** | **空仓** | 系统不会默认给你「持有茅台」之类 |
| **必跟名单** `watch_stocks` | 强制进入深度研究的代码 | **不是持仓**，不能据此写「持有/卖出」 |
| **模拟账本**（文末折叠附录） | 「若完全按建议执行」的评估 | 不是你的真实账户 |

跑任务规则：说明了持仓就写入；只说「跑一轮」而未提持仓 → **按空仓**。

### 报告结构

1. **数据源说明（本轮）**：文首表格——尝试连了哪些源、各取什么数据、是否拿到、后面怎么用（含备源/失败原因）  
2. **结论卡（速读）**：【主结论】分析/预测/动作 + 【侧栏】争议叙事 + 板块/逻辑链  
3. **详细论证（§0–§6）**：完整思路与证据（§1.1 机制层，§3 信息完备性）

### 邮件怎么读
- **正文**：结论卡 + 详细论证，已转成 HTML（手机邮箱可直接排版）  
- **附件**：完整 `.md` 报告（及 `trend.md`）；需要全文/存档时看附件  
- 数据源表、模拟账本等不进正文，只在附件 md 里  

### 系统在做什么

| 目标 | 含义 | 主要落在哪里 |
|------|------|----------------|
| **分析（Diagnosis）** | 现在发生了什么、多空力量在哪、数据可信度如何 | 结论卡「分析」· §0 情报 · §1 市场 · §2 板块 · §3 个股 · 数据质量 |
| **预测（Outlook）** | 未来数周～数季更可能怎么走、什么会推翻判断 | 结论卡「预测 / 动作 / 逻辑链」· §1 · §4 · §6 |

中长线默认观察期是**数周到数个季度**，不是明天涨跌。

## 1. 结论卡怎么读（优先）

只花 2–3 分钟时，按这个顺序：

### 分析：现在怎么看
- **环境**：阶段 · 风格 · 风险 · 置信度  
- **主驱动 / 配置倾向**  
- 若有 **⚠️ 可信度警告**（遴选失败、数据降级）：少信新开仓  

### 预测：接下来怎么预期
- **主情景** · **主要风险 / 若出现则认错** · **相对上周**

### 争议叙事 / 尾部情景（侧栏）
- 美债流动性、AI 拥挤、量化微观结构、政策市/护盘出清等**高争议话题**挂在这里  
- 每条含：来源类型（硬数据 / 市场定价 / 网络叙事）· 概率粗分 · **确认信号** · **证伪信号**  
- **不是主剧本**：无确认信号不得当成买入理由；用来避免报告「只讲中庸主线」

### 决策流程（分阶段结论）
固定四步，每步都有结论，避免把「研究 buy」误当成「可以开仓」：

1. **①个股研究**：`research_rating`（观点，可大量为 buy）  
2. **②组合草案**：LLM 给出的动作/仓位 + 草案摘要（**会被终局覆盖**）  
3. **③多空辩论**：凡草案为 buy/add 均辩论；裁判 bear 可打回观察  
4. **④风控终局**：仓位上限、空仓约束、微观结构、数据质量等硬校验后的**可执行动作**

报告里会有对照表：`①研究评级 | ②组合草案 | ③辩论后 | ④风控终局`。  
**只有④的 buy/add（仓位>0）** 才进入模拟盘；`portfolio_summary` 也是④结束后规则生成的终局摘要（草案另标「对照」）。

### 动作：怎么做（④风控终局）
- 基于你**声明的真实持仓**（空仓会标明）；与文末「模拟账本」无关  
- 空仓时只应出现 **买入 / 观察**；若出现「持有/卖出」是系统校验应拦掉的异常  
- 这是**给你本人的仓位纪律指令**，不是①研究评级，也不是模拟盘状态

### 板块：赛道态度
- 含「关注板块」+ 可能的资金流「自动扩」板块  
- 例：`新能源 … 赛道可看，个股等确认再动 → 某代码观察`

### 逻辑链
- 只写推理骨架：`情报 → 市场阶段/风格 → 配置倾向 → 板块态度`  
- **不按票展开**；个股见结论卡「动作」与 §3 决策链  
- 板块层最多一行摘要（可带「终局以观察为主」这类动作类型，不列代码）

## 2. 详细论证：各节意义与读法

```
情报(发生了什么)
  → 市场阶段(大环境怎么走)
    → 板块筛选(关注+资金流自动扩)
      → 个股遴选漏斗(全A/板块 → 量化池 → 深度池；必跟不占 max_deep)
        → ①–④个股决策链（研究→草案→辩论→风控）
          → §4 买卖建议（仅终局指令）
            → 复盘
              → 趋势
                → 附录：模拟账本（折叠）
```

| 结论卡块 | 主要核对正文 |
|----------|----------------|
| 决策流程 | 结论卡对照表（全市场一览）、§3 分票决策链 |
| 分析 | §0、§1、文首数据质量 |
| 预测 | §1、§4 总述、§6 |
| 动作 | §4（④终局；推理见 §3） |
| 板块 / 逻辑链 | §2、§3、§4 |

### §0 情报综述
把新闻、政策、舆论压成「本周中期相关」主题。舆情分不是涨跌预测。

### §0.1 叙事雷达
规则扫描四条轨道（美债流动性、AI 泡沫/拥挤、量化微观结构、政策市/国家队）。  
命中只表示「公开文本里出现线索」，要等 §1 侧栏的确认/证伪信号才升权。

### §1 市场阶段
判断未来数周指数/风格环境。风险 high → 少开仓。  
含 **§1.0 全球流动性硬指标**（美债/USD/CNY，主结论）、**§1.1 微观结构**（机制层），以及 **【侧栏】争议叙事 / 政策市假说**。  
「美债危机」故事仍在侧栏；利率已上行等硬事实进 §1.0。

### §3 信息完备性与盈利预期修正
- **信息完备性**：`public_info_sufficient` / `gap_suspected`（缺口→观望，非指控内幕）  
- **盈利预期修正**：预告+财务趋势上修/下修；下修时系统会拦 buy/add

### §2 板块筛选
对赛道做配置方向研究，**不是今日买哪只票**。  
标注「关注」= 你配置的 `watch_sectors`；「自动扩」= 资金流入前列补充。

### §2.1 个股遴选漏斗（白话）
1. 从全 A 现货（或板块成分）拿一批候选  
2. 去掉 ST、成交额过低的票；高 PE / 负 PE **默认不硬踢**，只打分降权  
3. 量化打分取前约 50 只（量化池）  
4. 深度分析最多再加约 15 只新票 + 全部必跟（必跟不占 15 的名额）  

若行情失败回退「只剩必跟」：会进 **数据质量降级**，结论卡有警告——**不要当成已经全市场海选**。

### §3 个股决策链（①研究→②草案→③辩论→④风控）
每只票一段完整推理链：基本面/赔率/叙事 → 组合草案 → 多空辩论 → 风控终局。  
**①研究评级 ≠ 可开仓指令**；为何从 buy 变成 watch，在这节按票核对。

### §4 买卖建议
承接 §3 各票的 **④风控终局**，只列可执行指令（仓位/止损/失效）+ 一行回指决策链。  
辩论全文与因子细节不再重复堆在这里。

### §5 复盘与经验
默认近 60 日。浮盈亏只作轨迹，不等于预测失败。  
空仓时复盘仍可覆盖「当时建议 buy/watch 是否合理」，不会假装你持有某票。

### §6 趋势更新
跨周剧本有没有换。完整版见 `reports/trend.md`。

### 附录：模拟账本
折叠区。缺仓位%时**不会**静默按 10% 开仓。  
会写清**本轮为什么成交 / 为什么不调仓**（承接 §4 终局；即使全是观察也要说明「无可执行开仓」）。

## 3. 各维度关系（空仓示例）

不要用「已有茅台仓」当默认故事。空仓时更典型的链条：

```
§1 风格=科技成长为主
  → §2 半导体 high 但拥挤/贵 → 不宜追高
  → §2 新能源 high → §3 某票研究偏多 → §4 观察（时机未到）
  → §2 银行 medium → §3 某银行低估值 → §4 买入（新建仓建议，不是「加仓」）
```

| 板块结论 | 个股动作（空仓） | 是否矛盾？ |
|----------|------------------|------------|
| 新能源 high、左侧窗口 | → **观察** | **不矛盾**：赛道可看，时机未到 |
| 半导体 high、拥挤 | 深度池可无对应买入 | 板块用于**回避追高** |
| 银行 medium、估值便宜 | → **买入** | 空仓下的新建仓，不是「加仓已有持仓」 |

若你**声明**了持仓，才会出现持有 / 加仓 / 卖出。

## 4. 外行读报检查清单（5 分钟）

1. 结论卡：分析 → 预测 → 动作 → 板块 → 逻辑链  
2. 文首 **数据质量** / 遴选警告：degraded → 少信新开仓  
3. 动作区是否标明空仓？有没有误把必跟当持仓？  
4. 模拟账本是否被误读成自己的仓？（应忽略或只当回测）  
5. 与上周：结论卡「相对上周」+ §6

## 5. 「分析」与「预测」速查

| 你想知道的问题 | 先看 | 再核对 |
|----------------|------|--------|
| 现在发生了什么？ | 结论卡·分析 | §0 |
| 大盘中期怎么走？ | 结论卡·预测 | §1、§6 |
| 哪类资产更值得配？ | 结论卡·板块 | §2 |
| 维度是否串得通？ | 结论卡·逻辑链 | §2 / §4 |
| 池子里公司质地？ | — | §3 |
| 我现在具体怎么做？ | 结论卡·动作 | §4 |
| 什么情况下认错？ | 结论卡·若出现则认错 | 各节失效条件 |
| 以前错在哪？ | — | §5 |

## 6. 字段速查

- **舆情分 / 因子分**：半客观分数，需结合拥挤、资金、失效条件  
- **置信度**：对判断/动作的把握；低置信度仍可能 watch  
- **研究评级 vs 买卖动作**：①观点 vs ④指令；可以不一致（常见：研究 buy → 终局 watch）  
- **portfolio_summary**：报告展示的是④终局规则摘要；LLM 的草案摘要仅作对照  
- **必跟 / 量化池 / 深度池 / 声明持仓**：四套不同名单，勿混用
