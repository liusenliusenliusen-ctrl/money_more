# money_more 报告解读指南

面向「想看懂报告、但不想当交易员」的读者。  
配套报告由 `report/writer.py` 生成（标题为「中长线周期决策报告」）。

---

## 0. 先记住四件事

### 阅读分层（主结论 vs 侧栏）

| 层级 | 写什么 | 怎么用 |
|------|--------|--------|
| **【主结论】** | 阶段、配置、买卖动作 | 可执行、可复核 |
| **【机制层】** | 同向性、跌停潮、成交集中等微观结构 | 可进入仓位纪律，≠「量化有罪」 |
| **【侧栏】** | 争议叙事、政策市假说、叙事雷达 | 须确认/证伪；不能单独当买入理由 |

### 持仓怎么算

| 概念 | 是什么 | 不是什么 |
|------|--------|----------|
| **声明持仓** `holdings` | 你明确写入 `config.yaml` 的真实仓位 | — |
| **未声明 / `[]`** | **空仓** | 系统不会默认给你「持有茅台」之类 |
| **深度池** | `screen` 自动量化遴选进 LLM 细读的代码 | 不是你的持仓；有 holdings 时持仓会强制并入 |
| **模拟账本**（`*-sim.md` 小报告） | 「若完全按建议执行」的评估 | 不是你的真实账户；邮件不附送 |

跑任务规则：说明了持仓就写入；只说「跑一轮」而未提持仓 → **按空仓**。

### 报告结构

1. **数据源说明（本轮）**：文首表格——尝试连了哪些源、各取什么数据、是否拿到、后面怎么用（含备源/失败原因）  
2. **结论卡（速读）**：**A** 主结论（A1→A2→A3）→ **B** 推理链（B1→B2）→ **C** 侧栏  
3. **详细论证**：子节 **A→B→C** 展开证据 → **D** 趋势更新  
4. **独立小报告**（不进邮件）：`YYYY-MM-DD-review.md` 复盘与经验 · `YYYY-MM-DD-sim.md` 模拟账本  

### 邮件怎么读
- **正文**：仅结论卡（HTML）  
- **附件**：仅主报告 `.md`（含详细论证与趋势）；**不附**复盘/模拟小报告、不附 `trend.md`  

### 系统在做什么

| 目标 | 含义 | 主要落在哪里 |
|------|------|----------------|
| **分析（Diagnosis）** | 现在发生了什么、多空力量在哪、数据可信度如何 | 结论卡 A1 · 详细论证 A1/A2/B1/B2 · 数据质量 |
| **预测（Outlook）** | 未来数周～数季更可能怎么走、什么会推翻判断 | 结论卡 A2/A3/B · 详细论证 A2 · D 趋势 |

中长线默认观察期是**数周到数个季度**，不是明天涨跌。

## 1. 结论卡怎么读（优先）

只花 2–3 分钟时，按 **A → B → C** 顺序：

### A. 主结论（连续读完再往下）
- **A1 分析**：环境 · 主驱动 · 配置倾向 · 流动性/微观结构要点  
- **A2 预测**：主情景 · 主要风险 / 认错 · 相对上周（上述字段**全文**）  
- **A3 动作（④风控终局）**：声明持仓下的指令；**理由全文不截断**；空仓时一般只有买入/观察  

### B. 推理链（一体两层）
- **B1 宏观→板块**：情报 → 市场 → 配置 → 赛道态度（情报句全文）  
- **B2 个股决策链**：①研究 → ②组合草案（双分析师→**综合**）→ ③辩论 → ④风控  
  - 结论卡 B2 有「步骤说明」与综合取舍审计；①研究评级 ≠ 开仓；**只有④已入选 buy/add（仓位>0）**进模拟盘  
  - 「观察·未入选」=综合未写入组合（有意搁置），不是漏跑  
  - 顺序：先 **②草案摘要**（对照）→ 再 **④终局组合摘要**  

### C. 侧栏（整块在最后）
- 争议叙事 / 政策市假说：确认·证伪·若成立**全文**；须确认/证伪才升权，**不得单独当买入理由**  
- 与 A 分层；读完动作后再看侧栏

## 2. 详细论证：各节意义与读法

详细论证**镜像结论卡**，用来核对依据，不是再讲一遍结论：

```
结论卡 A/B/C
  ↕ 核对
主报告
  ## 详细论证 A/B/C
  ## D 趋势更新
独立小报告（本地存档，邮件不附送）
  *-review.md  复盘与经验
  *-sim.md     模拟账本
```

| 结论卡 | 详细论证核对处 |
|--------|----------------|
| A1 分析 | **A1** 情报综述 |
| A2 预测 | **A2** 市场阶段 + 流动性 + 微观结构 |
| A3 动作 | 结论卡全文理由；详细论证 **A3 动作索引**；纪律字段在 **B2④** |
| B1 | **B1** 板块筛选 + 遴选漏斗 |
| B2 | **B2** 分票决策链 |
| C | **C** 争议/政策市/雷达（一处收齐） |

### A1 情报综述
把新闻、政策、舆论压成「本周中期相关」主题。舆情分不是涨跌预测。

### A2 市场阶段与展望
判断未来数周指数/风格环境。风险 high → 少开仓。  
含 **全球流动性硬指标**（美债/USD/CNY）与 **微观结构**（机制层，可进仓位纪律）。  
「美债危机」故事在 **C**；利率已上行等硬事实在 A2。

### A3 动作：怎么做（索引）
不重复结论卡逐票理由；给持仓基准、组合摘要与一览。止损/目标/失效见 **B2④**。

### B1 板块筛选 + 遴选漏斗
对赛道做配置方向研究，**不是今日买哪只票**。  
「关注」=`watch_sectors`；「自动扩」=资金流入前列。漏斗白话：
1. 全 A 现货（或板块成分）候选  
2. 去 ST、低流动性；高/负 PE 默认不硬踢，只降权  
3. 量化池约 50 → 深度池约 15 新票（有声明持仓则强制并入、不占 15）  

遴选降级时结论卡有警告——**不要当成已全市场海选**。

### B2 个股决策链（①→④）

每只票：①研究 → ②组合草案（双分析师→**综合**）→ ③辩论 → ④风控终局（含止损/目标/失效）。  
结论卡 B2 有「步骤说明」；表中「-」=该阶段无记录，不是「同上」。  
**①研究评级 ≠ 可开仓**；信息完备性缺口→观望；盈利下修会拦 buy/add。

### C 展开侧栏
争议叙事、政策市假说、叙事雷达线索原文。须确认/证伪才升权。

### D 趋势更新（主报告内）
跨周剧本有没有换。完整版见 `reports/trend.md`。

### 复盘小报告（`*-review.md`）
默认近 60 日。浮盈亏只作轨迹，不等于预测失败。邮件不附送。

### 模拟账本小报告（`*-sim.md`）
评估「若完全按 A3 终局执行」。缺仓位%时**不会**静默按 10% 开仓。邮件不附送。

## 3. 各维度关系（空仓示例）

不要用「已有茅台仓」当默认故事。空仓时更典型的链条：

```
A2 风格=科技成长为主
  → B1 半导体 high 但拥挤/贵 → 不宜追高
  → B1 新能源 high → B2 某票研究偏多 → A3 观察（时机未到）
  → B1 银行 medium → B2 某银行低估值 → A3 买入（新建仓建议，不是「加仓」）
```

| 板块结论 | 个股动作（空仓） | 是否矛盾？ |
|----------|------------------|------------|
| 新能源 high、左侧窗口 | → **观察** | **不矛盾**：赛道可看，时机未到 |
| 半导体 high、拥挤 | 深度池可无对应买入 | 板块用于**回避追高** |
| 银行 medium、估值便宜 | → **买入** | 空仓下的新建仓，不是「加仓已有持仓」 |

若你**声明**了持仓，才会出现持有 / 加仓 / 卖出。

## 4. 外行读报检查清单（5 分钟）

1. 结论卡：**A** 分析→预测→动作 → **B** 推理链 → **C** 侧栏  
2. 文首 **数据质量** / 遴选警告：degraded → 少信新开仓  
3. 动作区是否标明空仓？理由是否完整？有没有误把深度池代码当持仓？  
4. 模拟账本是否被误读成自己的仓？（应忽略或只当回测）  
5. 与上周：结论卡「相对上周」+ 主报告 D 趋势

## 5. 「分析」与「预测」速查

| 你想知道的问题 | 先看 | 再核对 |
|----------------|------|--------|
| 现在发生了什么？ | 结论卡·A1 | 详细论证 A1 |
| 大盘中期怎么走？ | 结论卡·A2 | 详细论证 A2、D 趋势 |
| 哪类资产更值得配？ | 结论卡·B1 | 详细论证 B1 |
| 维度是否串得通？ | 结论卡·B | 详细论证 B1/B2 |
| 池子里公司质地？ | — | 详细论证 B2① |
| 我现在具体怎么做？ | 结论卡·A3 | B2④（止损/失效） |
| 什么情况下认错？ | 结论卡·若出现则认错 | B2④ 失效条件 |
| 以前错在哪？ | — | `*-review.md` |

---

## 6. 字段速查

- **舆情分 / 因子分**：半客观分数，需结合拥挤、资金、失效条件  
- **置信度**：对判断/动作的把握；低置信度仍可能 watch  
- **研究评级 vs 买卖动作**：①观点 vs ④指令；可以不一致（常见：研究 buy → 终局 watch）  
- **portfolio_summary**：报告展示的是④终局规则摘要；LLM 的草案摘要仅作对照  
- **量化池 / 深度池 / 声明持仓**：三套不同名单，勿混用
