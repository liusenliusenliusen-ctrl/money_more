# money_more 报告解读指南

面向「想看懂报告、但不想当交易员」的读者。  
配套示例：`reports/2026-07-12.md`（与当前 `report/writer.py` 模板一致）。

---

## 0. 先记住两件事

报告分两层：

1. **结论卡（速读）**：开头五块——**分析 / 预测 / 动作 / 板块 / 逻辑链**。只想要结论时看这里。  
2. **详细论证（§0–§6）**：完整思路与证据。标题下有一句说明：「供核对结论卡依据」。

本系统本质上在做两件事（结论卡已按此拆开）：

| 目标 | 含义 | 主要落在哪里 |
|------|------|----------------|
| **分析（Diagnosis）** | 现在发生了什么、多空力量在哪、数据可信度如何 | 结论卡「分析」· §0 情报 · §1 市场 · §2 板块 · §3 个股 · 数据质量 |
| **预测（Outlook）** | 未来数周～数季更可能怎么走、什么会推翻判断 | 结论卡「预测 / 动作 / 逻辑链」· §1 主驱动/失效 · §4 买卖建议 · §6 趋势 |

这里的「预测」**不是**「某只股票下周涨 X%」，而是：

- 中期市场环境（震荡 / 趋势、成长 / 价值）
- 哪些板块更值得跟踪或回避
- 对关注池个股：偏多 / 观望 / 持有 / 减仓，以及**失效条件**

中长线默认观察期是**数周到数个季度**，不是明天涨跌。

---

## 1. 结论卡怎么读（优先）

只花 2–3 分钟时，按这个顺序：

### 分析：现在怎么看
- **环境**：阶段 · 风格 · 风险 · 置信度（一句话大盘剧本）
- **主驱动 / 配置倾向**：钱和叙事往哪边偏
- 若干条关键事实或**矛盾**（不确定性写在这里）

### 预测：接下来怎么预期
- **主情景**：中期最可能的路径（浓缩预测）
- **主要风险 / 若出现则认错**：事后验证用的「打叉条件」
- **相对上周**：continuation / shift / reversal —— 剧本有没有换

### 动作：怎么做
- 每条一行：`持有/观察/加仓/买入/卖出` + 代码 + 置信度 + 仓位 + 板块 + 短理由  
- 这是**组合指令**，不是研究评级

### 板块：赛道态度
- 每条：优先级 · 政策/景气/估值/拥挤 · **态度句** · 若有则 `→ 代码+动作`  
- 例：`新能源 … 赛道可看，个股等确认再动 → 300750观察`

### 逻辑链：维度如何串起来
- 把漏斗写成可核对的因果句：  
  `情报主题 → 市场阶段/风格 → 板块态度 → 个股研究评级 → 组合动作`
- 例：新能源 high → 研究 buy → **观察** 宁德（逻辑对、时机未到，并不矛盾）
- 板块 high 但池子无票：会写「关注池暂无对应个股动作（仍约束追高/回避）」

读完结论卡若无疑问，可以不往下翻。有疑问再进「详细论证」。

---

## 2. 详细论证：各节意义与读法

整体仍是「漏斗」：宏观 → 板块 → 个股 → 可执行动作 → 复盘 → 趋势。

```
情报(发生了什么)
  → 市场阶段(大环境怎么走)
    → 板块筛选(钱更可能去哪一类资产)
      → 个股研究(池子里谁质量/估值够格)
        → 买卖建议(在约束下怎么做)
          → 复盘(上次判断对不对)
            → 趋势(跨周是否换了剧本)
```

与结论卡的关系：

| 结论卡块 | 主要核对正文 |
|----------|----------------|
| 分析 | §0、§1 |
| 预测 | §1、§4 总述、§6 |
| 动作 | §4 各条建议 |
| 板块 / 逻辑链 | §2「落到动作」、§3 评级、§4「承接板块」 |

### §0 情报综述 ——「事实与噪声过滤器」

**意义**：把新闻、政策、舆论压成「本周中期相关」主题，避免被日内电报带跑。

**怎么读**：

- **执行摘要 / 今日主题**：本周定价叙事是什么  
- **量化舆情分 (0–100)**：规则情绪分，**不是涨跌预测**  
  - 约 0–30 极冷 · 30–45 谨慎 · 45–55 中性 · 55–70 偏暖 · 70+ 偏热（易拥挤）  
- **舆情温度**（hot/warm/neutral/cold…）：定性热度  
- **政策信号 [positive/negative]**：中期政策方向，不是利好就立刻买  
- **风险旗标**：应写进决策的坏情景  

**用法**：回答「环境叙事」；不要单凭舆情分下单。

### §1 市场阶段 ——「大盘剧本」

**意义**：判断未来数周指数/风格环境，并给出板块配置倾向。

| 字段 | 含义 | 怎么用 |
|------|------|--------|
| **阶段**（如「震荡偏强，结构性行情」） | 指数难单边，赚钱靠结构 | 不宜满仓赌方向 |
| **风格**（如「题材驱动，科技成长为主」） | 偏好主题/成长还是价值 | 消费可能「逻辑对但涨不动」 |
| **风险** low/medium/high | 组合风险偏好 | high → 少开仓、多现金 |
| **置信度** 0–1 | 对阶段判断的把握 | &lt;0.5 多看少动 |
| **主驱动** | 未来 1–2 季度定价第一因素 | 跟踪清单 |
| **政策基调** | supportive / neutral / tightening | 与风险旗标对照 |
| **板块配置倾向** | 顶层风格建议 | 应与结论卡/§4 一致 |
| **矛盾** | 多空都说得通的地方 | 不确定性标注 |
| **跨日 continuity** | 相对上周延续还是转折 | continuation = 剧本未换 |

常见阶段：牛/偏多 · 熊/偏空 · 震荡/结构性 · 筑底/磨底。  
常见风格：价值/高股息 · 成长/科技 · 题材/主题 · 防御。

### §2 板块筛选 ——「赛道优先级，不是下单清单」

**意义**：对关注板块做「值不值得作为配置方向」的研究，**不是今日买哪只票**。

| 标记 | 含义 |
|------|------|
| ✅ + high/medium/low | 研究优先级（非自动买入） |
| 政策 / 景气 / 估值 | 顺风逆风、景气方向、贵贱 |
| crowding_risk high | 拥挤，追高易挨打 |
| **落到动作** | 本轮显式交叉引用：态度 + 对应个股动作（或「暂无对应个股」） |

**用法**：

- high + 景气 up + 估值 cheap + 拥挤低 → 候选加仓赛道  
- high 但 expensive + crowding high → 逻辑对也不追  
- medium + 景气 down → 可看反弹，不宜当主线  

板块 ✅ **不会自动变成**买入；还要过 watchlist、因子、资金、持仓约束、辩论与风控。

### §3 个股研究 ——「池内研究备忘录」

| 字段 | 含义 |
|------|------|
| 评级 buy/hold/… | **研究观点**，尚未变成组合指令 |
| 质量 / 估值 | 基本面与贵贱 |
| 因子分 ~0–100 | &lt;45 偏弱 · 45–55 中性 · &gt;55 偏建设性 |
| 预期差 | 市场定价 vs 我们的判断 |
| 失效条件 | 出现则放弃原逻辑 |

**§3 vs §4**：研究可 buy，组合仍可 watch（时机未到）。

### §4 买卖建议 ——「在约束下的可执行预测」

优先读：

1. 开头「中期核心判断」→ 浓缩预测  
2. 组合仓位与风格说明  
3. 每条：**动作、置信度、承接板块、理由、证据链、失效条件**  
4. **风控覆写**（辩论降置信度、止损收紧等）

**承接板块**：显式写清本条动作承接了哪条板块结论（优先级/景气/估值/拥挤 + 态度句）。

| 动作 | 含义 |
|------|------|
| 加仓 / 买入 | 提高或新建仓位 |
| 持有 | 逻辑未失效，先不动 |
| 观察 | 逻辑可能对，时机/资金未到 |
| 卖出 | 逻辑失效或风险不可接受 |

**置信度 0–1**：对「这条动作」的把握，不是「一定会涨」。

### §5 复盘与经验 ——「上次预测的事后审计」

1. **维度复盘**：市场阶段/风格、板块优先级、主叙事、板块→动作联动是否说对  
2. **个股建议复盘**：满观察期荐股的对错与教训  
3. **经验库**：含 pattern / meta / 舆情 / 历史 dim:* 教训，会进入下一轮分析  

无新增复盘时，经验库仍可能非空（沿用旧教训）。

### §6 趋势更新 ——「跨周剧本有没有换」

把今日结论并进滚动趋势。适合和上周对比，不替代 §4。完整版见 `reports/trend.md`。

## 3. 各维度关系（示例：新能源 ✅ 但没买新能源股）

结论卡 **逻辑链** + §2 **落到动作** + §4 **承接板块** 表达的是同一件事：漏斗关系，不是「板块写了就下单」。

```
§1 风格=科技成长为主
  → §2 半导体 high 但拥挤/贵 → 逻辑链/§4：不宜追高（池子可无对应票）
  → §2 新能源 high 且偏左侧 → §3 宁德研究偏多 → §4 观察（资金/动量未稳）
  → §2 白酒 medium → §3 茅台偏多 → §4 持有（已是持仓，等旺季）
  → §1 地缘抬风险 + 持仓过集中 → §4 加仓平安做防御分散
```

用 `2026-07-12` 对照：

| 板块结论 | 个股动作 | 是否矛盾？ |
|----------|----------|------------|
| 新能源 high、左侧窗口 | 宁德 → **观察** | **不矛盾**：赛道可看，个股时机未到 |
| 半导体 high、拥挤 | 池子无纯半导体股 | 板块用于**回避追高**，不一定产出买入 |
| 白酒 medium、景气 down | 茅台 → **持有** | 板块一般、龙头可持有；已持仓优先 hold |

## 4. 外行读报检查清单（5 分钟）

1. **结论卡**：分析 → 预测（主情景/认错）→ 动作 → 板块 → **逻辑链**是否自洽  
2. 文首 **数据质量**：degraded 或缺失多 → 少信新开仓  
3. 存疑条目再翻 §1/§2/§4，核对「落到动作 / 承接板块」  
4. 有持仓：是否要求分散/降仓？失效条件是否清楚？  
5. 与上周：结论卡「相对上周」+ §6  

---

## 5. 「分析」与「预测」速查

| 你想知道的问题 | 先看 | 再核对 |
|----------------|------|--------|
| 现在发生了什么？ | 结论卡·分析 | §0 |
| 大盘中期怎么走？ | 结论卡·预测 | §1、§6 |
| 哪类资产更值得配？ | 结论卡·板块 | §2 |
| 维度是否串得通？ | 结论卡·逻辑链 | §2 落到动作、§4 承接板块 |
| 池子里公司质地？ | — | §3 |
| 我现在具体怎么做？ | 结论卡·动作 | §4 |
| 什么情况下认错？ | 结论卡·若出现则认错 | 各节失效条件 |
| 以前错在哪？ | — | §5 维度复盘 + 个股复盘 |

---

## 6. 字段速查

- **舆情分 / 因子分**：半客观分数，需结合拥挤、资金、失效条件  
- **置信度**：对判断/动作的把握；低置信度仍可能 watch/hold  
- **风险 medium**：允许结构仓，保留现金、控制单票  
- **研究评级 vs 买卖动作**：前者观点，后者指令；可以不一致（研究 buy、组合 watch）  
- **落到动作 / 承接板块 / 逻辑链**：同一套维度关系的三种展示，不矛盾时以结论卡逻辑链为准快速验证
