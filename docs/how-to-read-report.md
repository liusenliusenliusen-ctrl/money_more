# money_more 报告解读指南

面向「想看懂报告、但不想当交易员」的读者。  
配套报告由 `report/writer.py` 生成（标题为「中长线周期决策报告」）。

---

## 0. 先记住四件事

### 阅读分层（主线 vs 争议假说）

| 层级 | 写什么 | 怎么用 |
|------|--------|--------|
| **【主线】** | 阶段、配置、买卖动作；A1 可核对环境 | 可执行、可复核 |
| **【机制层】** | 同向性、跌停潮、成交集中等微观结构 | 可进入仓位纪律，≠「量化有罪」 |
| **【矛盾分支】** | 硬事实与叙事冲突时的「若改善 / 若恶化」 | 已触发冲突的跟踪清单；硬数据优先，不平均抹掉 |
| **【争议/未验证】**（挂在 A1 内、与主线分区） | 争议叙事、政策市假说、叙事雷达 | 须确认/证伪；不能单独当买入理由 |

矛盾分支的完整逻辑见 [`contradiction-branches.md`](contradiction-branches.md)（「分支」= if/else 分叉，不是相对主线的旁支题材）。

### 持仓怎么算

| 概念 | 是什么 | 不是什么 |
|------|--------|----------|
| **声明持仓** `holdings` | 你明确写入 `config.yaml` 的真实仓位 | — |
| **未声明 / `[]`** | **空仓** | 系统不会默认给你「持有茅台」之类 |
| **深度池** | `screen` 自动量化遴选进 LLM 细读的代码 | 不是你的持仓；有 holdings 时持仓会强制并入 |
| **研究段** | 市场/板块/个股 `research_rating`（结论卡 A1 + 深度池评级） | 不是下单指令 |
| **建议段** | 在研究之上、按 `holdings` 给出的终局动作（结论卡 A3） | 空仓时无 hold/sell/add |
| **模拟账本**（`*-sim.md` 小报告） | 「若完全按建议执行」的评估 | 不是你的真实账户；邮件不附送 |
| **数据源台账**（`*-datasources.md` 小报告） | 本轮连了哪些源、是否拿到、用在哪 | 不是运行/LLM 故障说明；邮件不附送 |

跑任务规则：说明了持仓就写入 → **研究 + 可操作建议**；只说「跑一轮」而未提持仓 → **按空仓**（研究完整，建议段无调仓）。

### 报告结构

1. **运行状态 / 数据台账入口**（主报告文首）：若本轮 LLM/连接中断，在此说明；数据连接明细链到独立小报告  
2. **结论卡（速读）**：**A** 主结论（A1 现在怎么看〔主线 + 争议/未验证〕→A2 预测→A3 建议）→ **B** 推理链（B1→B2）  
3. **详细论证**：子节 **A→B** 展开证据（A1 含争议假说展开）→ **D** 趋势更新  
4. **独立小报告**（不进邮件）：`YYYY-MM-DD-datasources.md` 数据源 · `YYYY-MM-DD-review.md` 复盘 · `YYYY-MM-DD-sim.md` 模拟账本  

### 邮件怎么读
- **正文**：仅结论卡（HTML）  
- **附件**：仅主报告 `.md`（含详细论证与趋势）；**不附**数据源/复盘/模拟小报告、不附 `trend.md`  

### 系统在做什么

| 目标 | 含义 | 主要落在哪里 |
|------|------|----------------|
| **研究（Research）** | 现在怎么看、深度池研究评级；不依赖你是否持仓 | 结论卡 A1 · 深度池评级 · 详细论证 |
| **建议（Advice）** | 在研究之上，按声明持仓给出可执行动作 | 结论卡 A3 · B2④ · 模拟盘跟④ |
| **预测（Outlook）** | 未来数周～数季更可能怎么走、什么会推翻判断 | 结论卡 A2 · 详细论证 A2 · D 趋势 |

中长线默认观察期是**数周到数个季度**，不是明天涨跌。

## 1. 结论卡怎么读（优先）

只花 2–3 分钟时，按 **A → B** 顺序：

### A. 主结论（连续读完再往下）
- **A1 研究 · 现在怎么看**  
  - **主线**：环境 · 主驱动 · 配置倾向 · **深度池研究评级**（`force`=持仓强制进池）  
  - **矛盾分支（若…则…）**：硬事实（如 PMI&lt;50）与叙事冲突时，拆成改善/恶化两条跟踪路径；确认一条动一条。详见 [`contradiction-branches.md`](contradiction-branches.md)  
  - **争议与未验证假说**：争议叙事 / 政策市假说（确认·证伪·若成立全文）；须确认才升权，**不得单独当买入理由**  
- **A2 预测**：主情景 · 主要风险 / 认错 · 相对上周（上述字段**全文**）  
- **A3 建议（④风控终局）**：声明持仓下的指令；**理由全文不截断**；空仓时一般只有买入/观察，并注明无调仓  

### B. 推理链（一体两层）
- **B1 宏观→板块**：情报 → 市场 → 配置 → 赛道态度（情报句全文）  
- **B2 个股决策链**：①研究 → ②建议草案（双分析师→**综合**）→ ③辩论 → ④风控  
  - 结论卡 B2 有「步骤说明」与综合取舍审计；①研究评级 ≠ 开仓；**只有④已入选 buy/add（仓位>0）**进模拟盘  
  - 「观察·未入选」=综合未写入组合（有意搁置），不是漏跑  
  - 顺序：先 **②草案摘要**（对照）→ 再 **④终局组合摘要**

## 2. 详细论证：各节意义与读法

详细论证**镜像结论卡**，用来核对依据，不是再讲一遍结论：

```
结论卡 A/B（A1 含主线 + 争议假说）
  ↕ 核对
主报告
  ## 详细论证 A/B
  ## D 趋势更新
独立小报告（本地存档，邮件不附送）
  *-datasources.md  数据源台账
  *-review.md       复盘与经验
  *-sim.md          模拟账本
```

| 结论卡 | 详细论证核对处 |
|--------|----------------|
| A1 主线 | **A1** 主线 · 情报综述 |
| A1 争议/未验证 | **A1** 争议叙事 / 政策市 / 雷达 |
| A2 预测 | **A2** 市场阶段 + 流动性 + 微观结构 |
| A3 动作 | 结论卡全文理由；详细论证 **A3 动作索引**；纪律字段在 **B2④** |
| B1 | **B1** 板块筛选 + 遴选漏斗 |
| B2 | **B2** 分票决策链 |

### A1 现在怎么看
**主线**：把新闻、政策、舆论压成「本周中期相关」主题；舆情分不是涨跌预测。  
**争议与未验证假说**：争议叙事、政策市假说、叙事雷达线索；须确认/证伪才升权，不得单独买入。

### A2 市场阶段与展望
判断未来数周指数/风格环境。风险 high → 少开仓。  
含 **全球流动性硬指标**（美债/USD/CNY）与 **微观结构**（机制层，可进仓位纪律）。  
「美债危机」故事在 **A1 争议区**；利率已上行等硬事实在 A2 主线/流动性。

### A3 动作：怎么做（索引）
不重复结论卡逐票理由；给持仓基准、组合摘要与一览。失效价带/观察目标/失效条件见 **B2④**（非日内止损纪律）。

### B1 板块筛选 + 遴选漏斗
对赛道做配置方向研究，**不是今日买哪只票**。  
「关注」=`watch_sectors`；「自动扩」=资金流入前列。漏斗白话：
1. 全 A 现货（或板块成分）候选  
2. 去 ST、低流动性；高/负 PE 默认不硬踢，只降权  
3. 量化池约 50 → 深度池约 15 新票（有声明持仓则强制并入、不占 15）  

遴选降级时结论卡有警告——**不要当成已全市场海选**。

### B2 个股决策链（①→④）

每只票：①研究 → ②组合草案（双分析师→**综合**）→ ③辩论 → ④风控终局（含失效价带/观察目标/失效条件）。  
结论卡 B2 有「步骤说明」；表中「-」=该阶段无记录，不是「同上」。  
**①研究评级 ≠ 可开仓**；信息完备性缺口→观望；盈利下修会拦 buy/add。

### D 趋势更新（主报告内）
跨周剧本有没有换。完整版见 `reports/trend.md`。

### 数据源小报告（`*-datasources.md`）
本轮数据连接台账（成功/备源/失败）与数据完整度。不含 DeepSeek 超时等运行故障（那些在主报告「运行状态」）。邮件不附送。

### 复盘小报告（`*-review.md`）
默认近 60 日。浮盈亏只作轨迹，不等于预测失败。邮件不附送。

### 模拟账本小报告（`*-sim.md`）
评估「若完全按 A3 终局执行」。缺仓位%时**不会**静默按 10% 开仓。邮件不附送。

## 3. 各维度关系（空仓示例）

不要用「已有茅台仓」当默认故事。空仓时更典型的链条：

```
A2 风格=科技成长为主
  → B1 半导体 high 但拥挤/贵 → 不宜追高
  → B1 新能源 high → B2 某票研究偏多 → A3 观察（时机未到）
  → B1 银行 medium → B2 某银行低估值 → A3 买入（新建仓建议，不是「加仓」）
```

| 板块结论 | 个股动作（空仓） | 是否矛盾？ |
|----------|------------------|------------|
| 新能源 high、左侧窗口 | → **观察** | **不矛盾**：赛道可看，时机未到 |
| 半导体 high、拥挤 | 深度池可无对应买入 | 板块用于**回避追高** |
| 银行 medium、估值便宜 | → **买入** | 空仓下的新建仓，不是「加仓已有持仓」 |

若你**声明**了持仓，才会出现持有 / 加仓 / 卖出。

## 4. 外行读报检查清单（5 分钟）

1. 结论卡：**A**（A1 主线+争议 → 预测 → 动作）→ **B** 推理链  
2. 主报告运行状态 / `*-datasources.md` 数据降级：degraded → 少信新开仓  
3. 动作区是否标明空仓？理由是否完整？有没有误把深度池代码当持仓？  
4. 模拟账本是否被误读成自己的仓？（应忽略或只当回测）  
5. 与上周：结论卡「相对上周」+ 主报告 D 趋势

## 5. 「分析」与「预测」速查

| 你想知道的问题 | 先看 | 再核对 |
|----------------|------|--------|
| 现在发生了什么？ | 结论卡·A1（主线） | 详细论证 A1 主线 |
| 有哪些未验证故事？ | 结论卡·A1 争议区 | 详细论证 A1 争议/雷达 |
| 大盘中期怎么走？ | 结论卡·A2 | 详细论证 A2、D 趋势 |
| 哪类资产更值得配？ | 结论卡·B1 | 详细论证 B1 |
| 维度是否串得通？ | 结论卡·B | 详细论证 B1/B2 |
| 池子里公司质地？ | — | 详细论证 B2① |
| 我现在具体怎么做？ | 结论卡·A3 | B2④（失效价带/观察目标/失效） |
| 什么情况下认错？ | 结论卡·若出现则认错 | B2④ 失效条件 |
| 以前错在哪？ | — | `*-review.md` |

## 6. 字段速查

- **舆情分 / 因子分**：半客观分数，需结合拥挤、资金、失效条件  
- **置信度**：对判断/动作的把握；低置信度仍可能 watch  
- **研究评级 vs 买卖动作**：①观点 vs ④指令；可以不一致（常见：研究 buy → 终局 watch）  
- **portfolio_summary**：报告展示的是④终局规则摘要；LLM 的草案摘要仅作对照  
- **量化池 / 深度池 / 声明持仓**：三套不同名单，勿混用
