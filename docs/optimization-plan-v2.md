## 2. 暴涨剔除阈值：检索与选定

### 2.1 约束与现有代码锚点

| 锚点 | 数值 | 含义 |
|------|------|------|
| 主板涨跌停 | 10%（ST 5%） | 监管硬顶 |
| 创业板/科创 | 20% | 同日 7% 在主板已是强脉冲，在创业板仍常见 |
| 因子软惩罚 `_chg_to_score` | ≥9 → 20 分；≥5 → 35 分 | 已反追高，但暴涨票仍可能因估值进池 |
| 硬门禁 `cross_check` | \|chg\|≥9.5 / 19.5 → 禁买 | 接近涨跌停才拦**交易**；进池应更早拦**研究预算** |

公开「选股公式」多把大涨当买入信号，与中长线目标相反；更有用的是 **A 股涨跌停分档 + 本系统已有阈值几何**，而不是追涨类教程。

### 2.2 历史深度池侧写（本仓库报告）

近几轮 `screen.top_candidates` 的当日涨跌多在 **&lt;5%**（max 约 4.7%）。说明：阈值主要清理 **漏斗中段的脉冲票**，不会「饿死」当前温和进池风格；真正要防的是题材日/高潮日占满深度预算。

周频（tue/fri）下，暴涨日踢出 → **下一轮冷却后仍可进池**，假阴性代价可控。

### 2.3 候选比较

| 阈值 | 优点 | 缺点 |
|------|------|------|
| 统一 5% | 极严反追高 | 普涨日误伤面大；创业板日常波动常过 5% |
| 统一 7% | 主板合适（≈70%×10% 限额） | **创业板过严**（7% 很常见） |
| 统一 9% | 贴近现有软惩罚与近涨停 | 主板偏松；5–9% 脉冲仍占预算 |
| **分档 7% / 14%** | 约 **70%×各自涨跌停**；与 `cross_check` 分板逻辑一致 | 实现稍多一行板别判断 |

### 2.4 拍板数值（实施默认）

```text
exclude_surge_pct:
  main_board: 7.0    # 代码 00/60 等，非 ST；当日涨跌幅 ≥ 则新票剔除
  chi_next_star: 14.0  # 代码 30/68；≈ 70% × 20%
  # ST/*ST：沿用现有 exclude_st，不另设暴涨阈值
holdings: 强制进池，不受暴涨剔除
```

配置可提供单一覆盖项 `exclude_surge_pct: 7.0`（若设置则两板共用——不推荐默认）。报告暴露 `excluded_surge_count` 与板别示例。

复盘后若主板误伤多 → 主板调至 8–9；若仍见 5–7% 题材占池 → 主板调至 5（创业板保持比例或 10–12）。

## 4. 框架轨细节（DeepSeek 增补摘要）

来自 `talk2.txt` 的可执行化（非再写长文）：

1. **矛盾要咬仓位**：列出 PMI vs 政策、融资下降 vs 反弹后，须压进攻/禁追涨式加仓，而不是仍「偏成长」无约束。  
2. **ERP 65% 等硬顶是宪法**：优化只约束「何时允许靠近上限」。  
3. **相对上周 / 风格 shift**：拉长到周频确认，减少一两根阳线改信仰。  
4. **复盘去 5 日噪声**：第二波写入 review prompt（本波可先在 DECISION prompt 加一句防短线止损叙事）。

与既有复盘教训合并：外生变量主导时护盘不升 phase；景气 down 不加仓；左侧需结构/资金企稳。

## 6. 验收

- 静音「当日涨跌、3–5 日主力加分、人气抬分」后，主结论方向与仓位逻辑大体仍在。  
- 构造/回放：景气 down + add → 被拦；主板 ≥7% / 创业板 ≥14% 新票不进深度池。  
- 矛盾档或极端拥挤触发时，配置倾向不得无约束「偏成长加仓」。  
- datasources：社融有台账；无 PE/PB / 政策抽取源 / Tushare 薄权限可见。  
- ERP/止损/硬门禁行为与改前一致。
